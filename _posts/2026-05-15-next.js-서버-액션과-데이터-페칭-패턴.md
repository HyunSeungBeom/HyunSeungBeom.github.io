## 표면적 이해
Next.js 서버 액션과 데이터 페칭 패턴은 클라이언트와 서버 사이의 데이터 전송을 효율적으로 관리하는 프레임워크입니다.

## Deep Dive

### 왜 필요한가?
- 이 기술이 해결하는 문제: 클라이언트와 서버 사이의 데이터 전송을 효율적으로 관리하여 페이지 로딩 시간을 줄이고 사용자 경험을 개선합니다.
- 이전 방식의 한계: 기존의 데이터 페칭 방법은 페이지 로딩 시간을 늦추거나, 데이터가 변경될 때마다 전체 페이지를 다시 로딩해야 하는 문제점이 있습니다.

### 내부 동작 원리
- 핵심 메커니즘 설명: Next.js 서버 액션과 데이터 페칭 패턴은 server components와 client components를 구분하여 데이터를 페칭합니다. 서버에서 데이터를 페칭하여 컴포넌트를 미리 렌더링하고, 클라이언트에서 필요한 데이터만 추가로 페칭합니다.
- ASCII 다이어그램으로 시각화:
```
  +---------------+
  |  Client    |
  +---------------+
           |
           |
           v
  +---------------+
  |  Server    |
  |  (Server   |
  |   Components) |
  +---------------+
           |
           |
           v
  +---------------+
  |  Database  |
  +---------------+
```

### 코드로 이해하기
```typescript
//예시) 서버 컴포넌트에서 데이터 페칭
import { useServerProps } from 'next/server';

const ServerComponent = () => {
  const props = useServerProps();

  // 서버에서 데이터 페칭
  const data = props.data;

  return (
    <div>
      <h1>서버 컴포넌트</h1>
      <p>데이터: {data}</p>
    </div>
  );
};

export default ServerComponent;
```

```typescript
// 잘못된 사용 예
// 클라이언트 컴포넌트에서 서버에서 데이터를 페칭
const ClientComponent = () => {
  const [data, setData] = useState(null);

  useEffect(() => {
    fetch('/api/data')
      .then(response => response.json())
      .then(data => setData(data));
  }, []);

  return (
    <div>
      <h1>클라이언트 컴포넌트</h1>
      <p>데이터: {data}</p>
    </div>
  );
};

// 올바른 사용 예
// 클라이언트 컴포넌트에서 서버에서 미리 페칭된 데이터 사용
const ClientComponent = () => {
  const props = useServerProps();

  const data = props.data;

  return (
    <div>
      <h1>클라이언트 컴포넌트</h1>
      <p>데이터: {data}</p>
    </div>
  );
};
```

### 비교 분석

| 구분 | Server Components | Client Components |
|------|------------------|-------------------|
| 데이터 페칭 | 서버에서 데이터 페칭 | 클라이언트에서 데이터 페칭 |
| 페이지 로딩 | 페이지 로딩 시간 줄임 | 페이지 로딩 시간 증가 |
| 사용자 경험 | 사용자 경험 개선 | 사용자 경험 저하 |

### 실전 팁
- Best Practice: 서버 컴포넌트에서 데이터 페칭을 사용하여 페이지 로딩 시간을 줄입니다.
- 흔한 실수와 해결법: 데이터 페칭을 클라이언트 컴포넌트에서 사용하여 페이지 로딩 시간을 늘리는 실수를 피합니다.
- 성능 관련 주의사항: 데이터 페칭을 여러번 사용하여 페이지 로딩 시간을 늘리는 것을 피합니다.
