## 표면적 이해
폰트 최적화와 FOIT, FOUT 해결은 웹페이지에서 폰트가 올바르게 표시되도록 하여 사용자 경험을 향상시키는 기술입니다.

## Deep Dive

### 왜 필요한가?
- 폰트 최적화 기술은 웹페이지의 로딩 속도와 사용자 경험을 개선하는 데 필요합니다. 이전 방식에서는 웹페이지가 로딩될 때 폰트를 다운받기 위해 시간이 오래 걸리거나, 폰트가 로딩되기 전에 텍스트가 기본 폰트로 표시되는 문제가 있었습니다. 이러한 문제를 FOIT (Flash of Invisible Text)와 FOUT (Flash of Unstyled Text)라고 합니다.

### 내부 동작 원리
- 핵심 메커니즘은 브라우저에서 폰트를 다운받기 위해 필요한 시간을 줄이고, 폰트가 로딩되기 전의 텍스트 표시를 최적화하는 것입니다. 폰트 최적화 기술은 폰트를 미리 다운받기  캐싱을 통해 로딩 시간을 줄입니다. 또한, FOIT와 FOUT를 방지하기 위해 텍스트가 표시되기 전까지 기본 폰트를 사용하거나, 로딩 중인 텍스트를 숨기는 방법을 사용합니다.
 
```
  +---------------+
  |  브라우저   |
  +---------------+
           |
           |
           v
  +---------------+
  |  폰트 미리 다운로드  |
  +---------------+
           |
           |
           v
  +---------------+
  |  텍스트 표시    |
  +---------------+
           |
           |
           v
  +---------------+
  |  폰트 캐싱      |
  +---------------+
```

### 코드로 이해하기

```typescript
// 폰트 미리 다운로드 예제
const font = new FontFace('myFont', 'url(https://example.com/myFont.woff2)');
document.fonts.add(font);

// FOIT를 방지하기 위한 예제
function loadFont() {
  const font = new FontFace('myFont', 'url(https://example.com/myFont.woff2)');
  document.fonts.add(font);
  return font.load();
}

loadFont().then(() => {
  // 폰트 로딩 완료 후 텍스트 표시
  document.body.style.fontFamily = 'myFont';
});
```

```typescript
// 잘못된 사용 예
// 텍스트 표시 후에 폰트 다운로드
document.body.style.fontFamily = 'myFont';
const font = new FontFace('myFont', 'url(https://example.com/myFont.woff2)');
document.fonts.add(font);

// 올바른 사용 예
// 폰트 다운로드 후에 텍스트 표시
const font = new FontFace('myFont', 'url(https://example.com/myFont.woff2)');
document.fonts.add(font);
font.load().then(() => {
  document.body.style.fontFamily = 'myFont';
});
```

### 비교 분석

| 구분 | 미리 다운로드 | 캐싱 | 기본 폰트 사용 |
|------|-------------|-----|----------------|
| 로딩 속도 | 빠름        | 빠름 | 느림            |
| FOIT 방지 | 가능       | 가능 | 불가능          |
| FOUT 방지 | 가능       | 가능 | 가능            |

### 실전 팁
- 폰트 최적화를 위해 미리 다운로드와 캐싱을 사용합니다.
- FOIT와 FOUT를 방지하기 위해 기본 폰트 사용이나 텍스트 숨김을 사용합니다.
- 성능 향상을 위해 폰트 파일을 최적화하고, 불필요한 폰트 삭제합니다.

### 한 줄 정리
폰트 최적화와 FOIT, FOUT 해결은 웹페이지의 사용자 경험을 개선하는 데 중요한 기술입니다.
