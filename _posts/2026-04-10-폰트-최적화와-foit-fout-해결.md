## 표면적 이해
폰트 최적화와 FOIT, FOUT 해결은 웹 페이지의 렌더링 성능을 향상시키고 사용자 경험을 개선하는 기술입니다.

## Deep Dive

### 왜 필요한가?
- 폰트 최적화와 FOIT, FOUT 해결은 웹 페이지의 렌더링 성능을 향상시키고 사용자 경험을 개선하는 데 중요한 역할을 합니다. 이전 방식의 한계는 웹 페이지가 폰트를 로딩하는 동안 비어있는 텍스트 또는 잘못된 텍스트가 표시되는 문제입니다.

### 내부 동작 원리
- 핵심 메커니즘은 웹 브라우저가 폰트를 로딩하는 동안 대체 텍스트 로딩 중인 텍스트를 표시하는 방식입니다. ASCII 다이어그램으로 시각화하면 다음과 같습니다.
```
                        +---------------+
                        |  웹 브라우저  |
                        +---------------+
                             |
                             |
                             v
                        +---------------+
                        |  폰트 로딩 중  |
                        |  (FOIT/FOUT)    |
                        +---------------+
                             |
                             |
                             v
                        +---------------+
                        |  대체 텍스트   |
                        |  또는 로딩 중  |
                        |  텍스트 표시  |
                        +---------------+
                             |
                             |
                             v
                        +---------------+
                        |  폰트 로딩 완료|
                        |  실제 텍스트 표시|
                        +---------------+
```

### 코드로 이해하기

```typescript
// 실제 동작을 보여주는 코드 예제
interface FontLoader {
  load(fontName: string): Promise<void>;
}

class FontLoaderImpl implements FontLoader {
  async load(fontName: string) {
    // 폰트 로딩 로직
    await this.loadFont(fontName);
  }

  private async loadFont(fontName: string) {
    // 폰트 로딩 중 대체 텍스트 또는 로딩 중인 텍스트 표시
    document.body.innerHTML = `로딩 중...`;
    await new Promise(resolve => setTimeout(resolve, 1000));
    // 실제 텍스트 표시
    document.body.innerHTML = `실제 텍스트`;
  }
}
```
