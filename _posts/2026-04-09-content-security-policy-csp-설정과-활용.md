## 표면적 이해
Content Security Policy(CSP) 설정과 활용은 웹 애플리케이션의 보안을 강화하는 데 중요한 역할을 합니다.

## Deep Dive

### 왜 필요한가?
- CSP는 크로스 사이트 스크립팅(XSS)와 같은 공격으로부터 웹 애플리케이션을 보호하는 데 중요한 역할을 합니다. 기존의 보안 방식은 공격이 이미 발생한 후에 처리하는 반면, CSP는 공격을 방지하는 방식으로 작동합니다.
- 이전 방식의 한계는 공격이 이미 발생했을 때 처리하는 것이기 때문에, CSP는 이러한 공격을 방지하는 데 더 효과적입니다.

### 내부 동작 원리
- CSP는 브라우저가 웹 페이지에서 로드할 수 있는 리소스를 제한하는 방식으로 작동합니다. 이를 통해 개발자는 웹 페이지에서 로드할 수 있는 스크립트와 스타일시트를 제어할 수 있습니다.
- 다음은 CSP의 내부 동작 원리를 보여주는 ASCII 다이어그램입니다.
```
                      +---------------+
                      |  Request    |
                      +---------------+
                             |
                             |
                             v
                      +---------------+
                      |  Browser    |
                      |  (CSP Parsing) |
                      +---------------+
                             |
                             |
                             v
                      +---------------+
                      |  Resource  |
                      |  (Script, Style) |
                      +---------------+
                             |
                             |
                             v
                      +---------------+
                      |  Load/Block  |
                      |  (CSP Enforcement) |
                      +---------------+
```

### 코드로 이해하기

```typescript
// CSP 설정 예
const csp = "default-src 'self'; script-src 'self' https://cdn.example.com;";

// CSP 설정을 헤더에 추가
const headers = {
  'Content-Security-Policy': csp,
};
```

```typescript
// 잘못된 사용 예
const wrongCsp = "default-src *;"; // 모든 소스를 허용하여 보안이 약해짐

// 올바른 사용 예
const correctCsp = "default-src 'self';"; // 자체 리소스만 허용
```

### 비교 분석

| 구분 | 기존 보안 방식 | CSP |
|------|---------|---|
| 공격 방식 | 공격 발생 후 처리 | 공격 방지 |
| 리소스 제한 | 없음 | 있음 |
| 보안 강도 | 낮음 | 높음 |

### 실전 팁
- Best Practice: CSP 설정을 엄격히 하여 가능한 많은 리소스를 제한합니다.
- 흔한 실수: CSP 설정을 너무 느슨하게 하여 공격을 허용하는 경우입니다.
- 성능 관련 주의사항: CSP 설정이 너무 엄격하여 필요한 리소스를 로드하지 못하는 경우가 있습니다.

### 한 줄 정리
CSP는 웹 애플리케이션의 보안을 강화하는 데 중요한 역할을 하는 설정 및 활용 방식입니다.
