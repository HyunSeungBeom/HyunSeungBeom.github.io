## 표면적 이해
CDN은 콘텐츠 딜리버리 네트워크의 약자로서, 다양한 서버 노드를 통해 사용자에게 콘텐츠를 더욱 빠르게 전달하는 기술이다.

## Deep Dive

### 왜 필요한가?
- CDN이 해결하는 문제는 사용자와 서버 사이의 물리적 거리를 최소화하여 콘텐츠 전달 시간을 줄이는 것과,의 트래픽을 처리하여 서버의 부담을 줄이는 것이다. 이전 방식에서는 사용자가 서버에 직접 요청을 보내야 했기 때문에, 서버와 사용자 사이의 거리에 비례하여 응답 시간이 증가하는 문제가 있었다.

### 내부 동작 원리
- CDN의 핵심 메커니즘은 콘텐츠를 사용자와 가까운 노드에 캐시하여, 사용자가 요청을 보낼 때 가장 가까운 노드에서 응답을 받을 수 있게 하는 것이다. 다음은 CDN의 동작을 간단한 ASCII 다이어그램으로 나타낸 것이다:
```
                      +---------------+
                      |  Origin Server  |
                      +---------------+
                             |
                             |
                             v
                      +---------------+
                      |  CDN Edge Node  |
                      +---------------+
                             |
                             |
                             v
                      +---------------+
                      |  사용자 브라우저  |
                      +---------------+
```
- 사용자가 브라우저에서 요청을 보내면, 가장 가까운 CDN Edge Node에서 캐시된 콘텐츠를 제공한다. 캐시가 존재하지 않을 경우, Edge Node는 Origin Server에 요청을 보내 캐시를 생성하고, 응답을 반환한다.

### 코드로 이해하기

```typescript
// 캐시 무효화 전략의 예
function invalidateCache(url: string) {
  // 캐시 무효화 요청을 CDN에 보냄
  fetch(`https://cdn.example.com/invalidate?url=${url}`);
}

// 캐시 제거 후 새로운 콘텐츠를 제공
invalidateCache('https://example.com/image.jpg');
```

```typescript
// 잘못된 사용 예: 캐시 무효화를 하지 않고 콘텐츠를 갱신하는 경우
function updateContent(url: string) {
  // 콘텐츠를 갱신하지만 캐시를 무효화하지 않음
  fetch(`https://example.com/update?url=${url}`);
}

// 올바른 사용 예: 캐시 무효화를 수행한 후 콘텐츠를 갱신하는 경우
function updateContentWithInvalidate(url: string) {
  // 캐시를 무효화하고 콘텐츠를 갱신함
  invalidateCache(url);
  fetch(`https://example.com/update?url=${url}`);
}
```

### 비교 분석

| 구분 | 직접 요청 | CDN 사용 |
|------|---------|---------|
| 응답 시간 | 긴 응답 시간 | 짧은 응답 시간 |
| 트래픽 부담 | 트래픽 부담 |낮은 트래픽 부담 |
| 콘텐츠 캐싱 | 불가능 | 가능 |

### 실전 팁
- Best Practice: 콘텐츠가 변경될 때마다 캐시를 무효화하여 사용자에게 최신 콘텐츠를 제공한다.
- 흔한 실수와 해결법: 캐시 무효화를  경우, 오래된 콘텐츠가 제공될 수 있으므로, 캐시 무효화 로직을 철저하게 구현해야 한다.
- 성능 관련 주의사항: 캐시를 너무 자주 무효화하면 성능에 부정적인 영향을 줄 수 있으므로, 캐시 무효화 전략을 신중하게 설계해야 한다.

### 한 줄 정리
CDN을 사용하여 콘텐츠를 사용자와 가까운 노드에 캐시함으로써, 사용자에게 더욱 빠르게 콘텐츠를 전달할 수 있으며, 캐시 무효화 전략을 통해 최신 콘텐츠를 제공할 수 있다.
