## 표면적 이해
Docker 컨테이너는 가상화 기술을 이용해 응용 프로그램을 실행하는 방법으로, 컨테이너 원리와 이미지 레이어 최적화를 이해하면 개발 및 배포 효율성을 높일 수 있다.

## Deep Dive

### 왜 필요한가?
컨테이너 기술은 여러 가지 문제를 해결해 준다. 예를 들어, 개발 환경이 다  같은 환경에서 개발된 프로그램을 같은 환경에서 실행해야 하는 문제를 해결해준다. 이전에는 가상 머신을 사용하여 이러한 문제를 해결했지만, 가상 머신은 매우 무겁고 느리다는 단점이 있다. Docker 컨테이너는 이러한 문제를 해결하면서도 가볍고 빠르다는 장점이 있다.

### 내부 동작 원리
Docker 컨테이너는 이미지 레이어를 사용하여 컨테이너를 생성한다. 이미지 레이어는 컨테이너의 기본 구성 요소를 제공하며, 이러한 레이어가 중첩되어 컨테이너를 생성한다.
```
          +---------------+
          |  호스트 OS  |
          +---------------+
                  |
                  |
                  v
          +---------------+
          | Docker 에 |
          +---------------+
                  |
                  |
                  v
          +---------------+
          |  컨테이너 런타임  |
          +---------------+
                  |
                  |
                  v
          +---------------+
          | 이미지 레이어 1 |
          +---------------+
                  |
                  |
                  v
          +---------------+
          | 이미지 레이어 2 |
          +---------------+
                  |
                  |
                  v
          +---------------+
          | 이미지 레이어 3 |
          +---------------+
                  |
                  |
                  v
          +---------------+
          |  컨테이너  |
          +---------------+
```
### 코드로 이해하기

```typescript
// Dockerfile 예제
FROM node:14
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build
EXPOSE 3000
CMD [ "npm", "start" ]
```

```typescript
// 올바른 사용 예
// Dockerfile에 각 명령어를 분리하여 이미지 레이어를 최적화한다.
FROM node:14 AS build-stage
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build

FROM node:14
WORKDIR /app
COPY --from=build-stage /app/build/ build/
EXPOSE 3000
CMD [ "npm", "start" ]
```

```typescript
// 잘못된 사용 예
// Dockerfile에 모든 명령어를 하나의 레이어에서 실행하여 이미지 크기가 커진다.
FROM node:14
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build
EXPOSE 3000
CMD [ "npm", "start" ]
```

### 비교 분석

| 구분 | 가상 머신 | Docker 컨테이너 |
|------|---------|-----------------|
| 운영 체제 | 별도의 OS 필요 | 호스트 OS 공유 |
| 메모리 사용량 | 높음 | 낮음 |
| 시작 시간 | 느림 | 빠름 |
| 이미지 크기 | 크다 | 작다 |

### 실전 팁
- Dockerfile을 작성할 때, 각 명령어를 분리하여 이미지 레이어를 최적화한다.
- 불필요한 파일을 제거하여 이미지 크기를 줄인다.
- 컨테이너를 실행할 때, `-it` 옵션을 사용하여 터미널에 trc 접근할 수 있게 한다.

### 한 줄 정리
Docker 컨테이너는 가상화 기술을 이용해 응용 프로그램을 실행하는 방법으로, 이미지 레이어를 최적화하여 개발 및 배포 효율성을 높일 수 있다.
