## 표면적 이해
React.memo, useMemo, useCallback은 리액트에서 성능 최적화를 위해서 사용되는 기술들입니다.

## Deep Dive

### 왜 필요한가?
이 기술들은 불필요한 렌더링을 방지하고, 성능을 개선하기 위해 사용됩니다. 이전에는 모든 컴포넌트가 상태나 속성이 변경될 때마다 렌더링이 발생했습니다. 하지만, 이러한 렌더링은 불필요한 경우도 많았습니다. 이러한 문제를 해결하기 위해 React.memo, useMemo, useCallback가 등장했습니다.

### 내부 동작 원리
React.memo는 컴포넌트의 props가 변경되지 않았을 때, 이전에 렌더링한 결과를 재사용합니다. useMemo와 useCallback은 함수형 컴포넌트에서 특정 함수 또는 값을 재계산할 때 사용됩니다. useMemo는 값을 재계산하고, useCallback은 함수를 재생성합니다.
```
+---------------+
|  컴포넌트   |
+---------------+
       |
       |
       v
+---------------+
| React.memo   |
|  (props 비교) |
+---------------+
       |
       |
       v
+---------------+
|  이전 렌더링  |
|  결과 재사용  |
+---------------+
```

### 코드로 이해하기

```typescript
// React.memo 예제
import React from 'react';

const MyComponent = React.memo((props) => {
  // 렌더링 로직
});

// useMemo 예제
import React, { useMemo } from 'react';

const MyComponent = () => {
  const currentValue = useMemo(() => {
    // 복잡한 계산 로직
  }, [종속값]);
};
```

```typescript
// 잘못된 사용 예: 불필요한 렌더링
import React from 'react';

const MyComponent = () => {
  const [count, setCount] = React.useState(0);
  const handleClick = () => {
    setCount(count + 1);
  };
  return <button onClick={handleClick}>{count}</button>;
};

// 올바른 사용 예: useCallback으로 함수를 재생성하지 않음
import React, { useCallback } from 'react';

const MyComponent = () => {
  const [count, setCount] = React.useState(0);
  const handleClick = useCallback(() => {
    setCount(count + 1);
  }, [count]);
  return <button onClick={handleClick}>{count}</button>;
};
```

### 비교 분석

| 구분 | React.memo | useMemo | useCallback |
|------|---|---|---|
| 용도 | 컴포넌트 렌더링 최적화 | 값 재계산 | 함수 재생성 |
| 종속값 | props | 종속값 | 종속값 |
| 반환값 | 컴포넌트 | 값 | 함수 |

### 실전 팁
- 불필요한 렌더링을 방지하기 위해 React.memo, useMemo, useCallback을 사용하세요.
- 종속값이 변경되지 않았을 때는 이전 결과를 재사용하세요.
- 성능에 민감한 컴포넌트에서는 React.memo를 사용하세요.
- 함수형 컴포넌트에서 특정 함수 또는 값을 재계산할 때 useMemo, useCallback을 사용하세요.

### 한 줄 정리
React.memo, useMemo, useCallback은 리액트에서 성능 최적화를 위해 사용되는 기술이며, 불필요한 렌더링을 방지하고, 성능을 개선하기 위해 사용됩니다.
