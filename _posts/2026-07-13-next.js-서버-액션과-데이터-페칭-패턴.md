## 표면적 이해
Next.js의 서버 액션과 데이터 페칭 패턴은 클라이언트와 서버 사이의 데이터 교환을 효율적으로 관리하는 기술입니다.

## Deep Dive

### 왜 필요한가?
- 이 기술이 해결하는 문제: 이전에는 클라이언트와 서버 사이의 데이터 교환을 관리하기 위해 많은 공수가 필요했습니다. 서버 액션과 데이터 페칭 패턴은 이러한 문제를 해결하기 위해 등장했습니다.
- 이전 방식의 한계: 이전에 사용하던 방식에서는 데이터를 가져오고 업데이트하는 데에 많은 코드가 필요했습니다. 또한, 데이터가 업데이트될 때마다 전체 페이지를 리렌더링해야 하는 문제도 있었습니다.

### 내부 동작 원리
- 핵심 메커니즘 설명: Next.js의 서버 액션은 클라이언트에서 발생한 액션을 서버에서 처리하고, 데이터를 업데이트하는 역할을 합니다. 데이터 페칭 패턴은 클라이언트에서 데이터를 가져오고, 캐싱하는 역할을 합니다.
- ASCII 다이어그램으로 시각화:

### 코드로 이해하기
```typescript
// Next.js의 getServerSideProps 함수 사용
import { GetServerSideProps } from 'next';

const HomePage = () => {
  // 데이터를 가져오는 함수
  const fetchData = async () => {
    const response = await fetch('https://api.example.com/data');
    const data = await response.json();
    return data;
  };

  return (
    <div>
      <h1>홈페이지</h1>
      <ul>
        {data.map((item) => (
          <li key={item.id}>{item.name}</li>
        ))}
      </ul>
    </div>
  );
};

export const getServerSideProps: GetServerSideProps = async () => {
  const data = await fetchData();
  return {
    props: {
      data,
    },
  };
};

export default HomePage;
```

```typescript
// 잘못된 사용 예
// 데이터를 가져오는 함수를 클라이언트에서 호출
const HomePage = () => {
  const [data, setData] = useState([]);

  useEffect(() => {
    const fetchData = async () => {
      const response = await fetch('https://api.example.com/data');
      const data = await response.json();
      setData(data);
    };
    fetchData();
  }, []);

  return (
    <div>
      <h1>홈페이지</h1>
      <ul>
        {data.map((item) => (
          <li key={item.id}>{item.name}</li>
        ))}
      </ul>
    </div>
  );
};

// 올바른 사용 예
// getServerSideProps 함수를 사용하여 데이터를 가져오기
export const getServerSideProps: GetServerSideProps = async () => {
  const data = await fetchData();
  return {
    props: {
      data,
    },
  };
};
```

### 비교 분석

| 구분 | SSR | SSG | CSR |
|------|---|---|---|
| Rendering | 서버에서 렌더링 | 빌드 타임에 렌더링 | 클라이언트에서 렌더링 |
| 데이터 페칭 | 서버에서 데이터 페칭 | 빌드 타임에 데이터 페칭 | 클라이언트에서 데이터 페칭 |
| 성능 | 좋음 | 최선 | 나쁨 |

### 실전 팁
- Best Practice: getServerSideProps 함수를 사용하여 데이터를 가져오고, 캐싱을 사용하여 성능을 개선합니다.
- 흔한 실수와 해결법: 데이터를 가져올 때에 에러를 처리하지 않으면 애플리케이션이 크래시할 수 있습니다. try-catch문을 사용하여 에러를 처리합니다.
- 성능 관련 주의사항: 데이터를 가져올 때에 너무 많은 요청을 보내면 성능이 저하될 수 있습니다. 캐싱을 사용하여 요청을합니다.
