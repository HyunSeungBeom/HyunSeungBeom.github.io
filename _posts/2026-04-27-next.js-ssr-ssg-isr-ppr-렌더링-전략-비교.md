## 표면적 이해
Next.js의 다양한 렌더링 전략인 SSR, SSG, ISR, PPR에 대해 깊이 있게 이해하고 비교해 방법입니다.

## Deep Dive

### 왜 필요한가?
Next.js의 렌더링 전략들은 사용자에게 빠르고 효율적인 웹 페이지를 제공하기 위해 필요한 기술입니다. 이전의 정적 사이트 생성(SSG)만으로는 동적 컨텐츠를 효율적으로 처리할 수 없으며, 서버 사이드 렌더링(SSR)만으로는 성능이 저하되는 문제가 있었습니다. 이러한 문제를 해결하기 위해 다음의 렌더링 전략들이 개발되었습니다.

### 내부 동작 원리
SSR은 서버에서 컨텐츠를 렌더링하고 클라이언트로 전송하는 방식입니다. SSG는 빌드 타임에 컨텐츠를 렌더링하여 정적인 HTML 파일을 생성하는 방식입니다. ISR은 빌드 타임에 컨텐츠를 렌더링하지만, 요청이 발생할 때마다 캐시된 컨텐츠를 반환하는 방식입니다. PPR은 클라이언트에서 부분적으로 페이지를 렌더링하는 방식입니다.

```
         +---------------+
         |  요청 발생  |
         +---------------+
                  |
                  |
                  v
         +---------------+
         |  SSR/SGG/ISR  |
         |  렌더링 처리  |
         +---------------+
                  |
                  |
                  v
         +---------------+
         |  클라이언트로  |
         |  응답 전송    |
         +---------------+
                  |
                  |
                  v
         +---------------+
         |  PPR 렌더링   |
         |  부분적 렌더링 |
         +---------------+
```

### 코드로 이해하기

```typescript
// next.config.js
module.exports = {
  // SSG 설정
  target: 'serverless',
  // ISR 설정
  experimental: {
    isr: true,
  },
};
```

```typescript
// page.tsx
import { useState, useEffect } from 'react';

function Page() {
  const [data, setData] = useState(null);

  useEffect(() => {
    // API 요청
    fetch('/api/data')
      .then((response) => response.json())
      .then((data) => setData(data));
  }, []);

  return (
    <div>
      {data ? (
        <div>
          {data.map((item) => (
            <div key={item.id}>{item.name}</div>
          ))}
        </div>
      ) : (
        <div>로딩 중...</div>
      )}
    </div>
  );
}

export default Page;
```

### 비교 분석

| 구분 | SSR | SSG | ISR | PPR |
|------|---|---|---|---|
| 렌더링 시기 | 요청 발생 시 | 빌드 타임 | 빌드 타임 | 클라이언트에서 부분적으로 |
| 성능 | 저하될 수 있음 | 빠름 | 빠름 | 빠름 |
| 캐싱 | 사용 안 함 | 사용 함 | 사용 함 | 사용 안 함 |

### 실전 팁
- 빌드 타임이 오래 걸리는 경우에 SSG와 ISR을 함께 사용하여 성능을 개선할 수 있습니다.
- 부분적으로 렌더링이 필요한 경우에 PPR을 사용하여 성능을 개선할 수 있습니다.
- 캐싱을 사용하여 성능을 개선할 수 있습니다.
