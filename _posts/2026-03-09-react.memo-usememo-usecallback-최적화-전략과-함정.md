## 표면적 이해
React.memo, useMemo, useCallback은 리액트에서 성능 최적화를 위해 사용되는 메서드입니다.

## Deep Dive

### 왜 필요한가?
- 이 기술이 해결하는 문제: 불필요한 리렌더링을 방지하고 성능을 개선하는 문제를 해결합니다.
- 이전 방식의 한계: 이전 방식에서는 불필요한 리렌더링이 발생하여 성능이 저하되었으며, 이는 사용자 경험에 악영향을 미쳤습니다.

### 내부 동작 원리
- 핵심 메커니즘 설명: React.memo, useMemo, useCallback은 모두 리액트의 Virtual DOM과 Reconciliation을 기반으로 합니다. React.memo는 컴포넌트의 프로퍼티가 변경되지 않을 때 리렌더링을 방지하며, useMemo와 useCallback은 특정값과 함수를 캐싱하여 불필요한 계산을 방지합니다.
- ASCII 다이어그램으로 시각화:
```
          +---------------+
          |  React.memo  |
          +---------------+
                  |
                  |
                  v
          +---------------+
          |  Virtual DOM  |
          +---------------+
                  |
                  |
                  v
          +---------------+
          |  Reconciliation|
          +---------------+
                  |
                  |
                  v
          +---------------+
          |  useMemo     |
          |  useCallback |
          +---------------+
```

### 코드로 이해하기

```typescript
// 올바른 사용 예
import React, { useState, useMemo, useCallback } from 'react';

function Counter() {
  const [count, setCount] = useState(0);
  const doubleCount = useMemo(() => count * 2, [count]);
  const increaseCount = useCallback(() => setCount(count + 1), [count]);

  return (
    <div>
      <p>Count: {count}</p>
      <p>Double Count: {doubleCount}</p>
      <button onClick={increaseCount}>Increase</button>
    </div>
  );
}
```

```typescript
// 잘못된 사용 예
import React, { useState, useMemo, useCallback } from 'react';

function Counter() {
  const [count, setCount] = useState(0);
  const doubleCount = useMemo(() => count * 2, []); // 의존성 배열이 비어있음
  const increaseCount = useCallback(() => setCount(count + 1), []); // 의존성 배열이 비어있음

  return (
    <div>
      <p>Count: {count}</p>
      <p>Double Count: {doubleCount}</p>
      <button onClick={increaseCount}>Increase</button>
    </div>
  );
}
```

### 비교 분석

| 구분 | React.memo | useMemo | useCallback |
|------|---|---|---|
| 사용목적 | 컴포넌트의 불필요한 리렌더링 방지 | 특정값의 캐싱 | 함수의 캐싱 |
| 의존성 배열 | 없음 | 필수 | 필수 |
| 사용처 | 컴포넌트 | 값, 함수 | 함수 |

### 실전 팁
- Best Practice: 의존성 배열을 사용하여 캐싱할 때 주의하여 사용합니다.
- 흔한 실수와 해결법: 의존성 배열을 비우거나, 의존성 배열에 들어가는 값을 잘못 지정하여 발생하는 문제를 주의합니다.
- 성능 관련 주의사항: 캐싱을 사용할 때 주의하여 사용하여 불필요한 계산을 최소화합니다.

### 한 줄 정리
React.memo, useMemo, useCallback은 리액트에서 성능 최적화를 위해 사용되는 메서드로, 의존성 배열을 사용하여 캐싱할 때 주의하여 사용해야 합니다.
