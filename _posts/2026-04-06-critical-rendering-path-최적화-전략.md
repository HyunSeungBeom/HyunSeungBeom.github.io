## 표면적 이해
Critical Rendering Path(CRP) 최적화 전략은 사용자에게 가장하게 콘텐츠를 렌더링하여 최고의 사용자 경험을 제공하는 기술입니다.

## Deep Dive

### 왜 필요한가?
- CRP 최적화는 웹 페이지의 로드 시간을 단축하고 사용자 경험을 향상하는 데 중요한 역할을 합니다. 이전 방식의 한계는 렌더링 프로세스가 복잡하고 비효율적으로 작동하여 로드 시간이 길어지는 문제를 해결하지 못했습니다.

### 내부 동작 원리
- CRP는 HTML, CSS, JavaScript 파일을 로드하여 렌더링하는 과정입니다. 이 때, 브라우저는 DOM 트리를 생성하고 스타일을 적용한 후 레이아웃과 페인트 과정을 거칩니다. 핵심 메커니즘은 아래의 ASCII 다이어그램으로 설명할 수 있습니다.

```
                      +---------------+
                      |  HTML 로드  |
                      +---------------+
                             |
                             |
                             v
                      +---------------+
                      |  DOM 트리 생성  |
                      +---------------+
                             |
                             |
                             v
                      +---------------+
                      |  CSS 파싱과 적용  |
                      +---------------+
                             |
                             |
                             v
                      +---------------+
                      |  레이아웃과 페인트  |
                      +---------------+
                             |
                             |
                             v
                      +---------------+
                      |  자바스크립트 실행  |
                      +---------------+
```

### 코드로 이해하기

```typescript
// CRP 최적화를 위한 예제: 자바스크립트 파일을 비동기적으로 로드
function loadScript(src: string) {
  const script = document.createElement('script');
  script.src = src;
  script.async = true;
  document.head.appendChild(script);
}
```

```typescript
// 잘못된 사용 예: 자바스크립트 파일을 head 섹션에 직접 추가
// document.head.innerHTML += '<script src="script.js"></script>';
// 올바른 사용 예: 자바스크립트 파일을 비동기적으로 로드
loadScript('script.js');
```

### 비교 분석

| 구분 | 적 로딩 | 비동기적 로딩 | 지연 로딩 |
|------|---------|---------|---------|
| 로딩 시기 | 페이지 로드 시 | 페이지 로드 후 | 필요 시 |
| 로딩 방식 | 블록킹 | 논블록킹 | 논블록킹 |
| 사용 예 | 초기 렌더링에 필요한 자바스크립트 | 초기 렌더링에 불필요한 자바스크립트 | 사용자 상호작용 후에 필요한 자바스크립트 |

### 실전 팁
- 초기 렌더링에 필요한 자바스크립트만 로드하고, 불필요한 자바스크립트는 비동기적으로 로드합니다.
- CSS 파일은 head 섹션에 포함하고, 자바스크립트 파일은 body 섹션의 끝에 포함합니다.
- 지연 로딩을 사용하여 사용자 상호작용 후에 필요한 자바스크립트를 로드합니다.
