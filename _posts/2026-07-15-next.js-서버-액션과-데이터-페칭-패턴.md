## 표면적 이해
Next.js 서버 액션과 데이터 페칭 패턴은 클라이언트 사이드 렌더링과 서버 사이드 렌더링을 모두 사용하는 하이브리드 아키텍처를 제공하는 Next.js의 핵심 기능 중 하나이다.

## Deep Dive

### 왜 필요한가?
- 이 기술이 해결하는 문제: 데이터를 효율적으로 가져오고 관리하는 문제
- 이전 방식의 한계: 이전에는 클라이언트 사이드 렌더링만 사용하거나 서버 사이드 렌더링만 사용하여 데이터를 가져오므로, 각각의 장단점이 있었다. 클라이언트 사이드 렌더링은 초기 로딩속도가 느리고, SEO에 취약하다는 단점이 있었다. 반면, 서버 사이드 렌더링은 페이지에 접근할 때마다 서버에 요청을 보내야 하므로, 서버의 부담이 증가할 수 있다.

### 내부 동작 원리
- 핵심 메커니즘 설명: Next.js의 서버 액션과 데이터 페칭 패턴은 getServerSideProps와 getStaticProps를 사용하여 서버에서 데이터를 미리 가져오고, 클라이언트에서 데이터를 가져오도록 설정할 수 있다.
```
                               +---------------+
                               |  사용자 요청  |
                               +---------------+
                                        |
                                        |
                                        v
                               +---------------+
                               |  Next.js 라우터  |
                               +---------------+
                                        |
                                        |
                                        v
                               +---------------+
                               | getServerSideProps |
                               |  또는 getStaticProps  |
                               +---------------+
                                        |
                                        |
                                        v
                               +---------------+
                               |  데이터 가져오기  |
                               +---------------+
                                        |
                                        |
                                        v
                               +---------------+
                               |  페이지 렌더링  |
                               +---------------+
```

### 코드로 이해하기

```typescript
// pages/index.tsx
import { GetServerSideProps } from 'next';

export const getServerSideProps: GetServerSideProps = async () => {
  const data = await fetch('https://api.example.com/data');
  const jsonData = await data.json();

  return {
    props: {
      data: jsonData,
    },
  };
};

function HomePage({ data }: { data: any }) {
  return (
    <div>
      <h1>홈페이지</h1>
      <p>{data.message}</p>
    </div>
  );
}

export default HomePage;
```

```typescript
// 잘못된 사용 예
// getServerSideProps에서 데이터를 가져오는 코드는 서버에서 실행되므로,
// 클라이언트 사이드에서만 사용되는 코드를 여기서 실행하면 안됩니다.
export const getServerSideProps: GetServerSideProps = async () => {
  // 브라우저에서만 사용되는 localStorage를 사용하고 있습니다.
  const storedData = localStorage.getItem('data');
  return {
    props: {
      data: storedData,
    },
  };
};

// 올바른 사용 예
// getServerSideProps에서 클라이언트 사이드에서만 사용되는 코드는 사용하지 말고,
// 서버에서 실행되는 코드만 사용하세요.
export const getServerSideProps: GetServerSideProps = async () => {
  const data = await fetch('https://api.example.com/data');
  const jsonData = await data.json();

  return {
    props: {
      data: jsonData,
    },
  };
};
```

### 비교 분석

| 구분 | getServerSideProps | getStaticProps |
|------|-------------------|---------------|
| 호출 시기 | 페이지에 접근할 때마다 호출됩니다. | 빌드할 때 호출됩니다. |
| 데이터 가져오기 | 서버에서 데이터를 가져옵니다. | 빌드할 때 데이터를 가져옵니다. |
| SEO | 검색 엔진에 친화적입니다. | 검색 엔진에 친화적입니다. |
| 성능 | 초기 로딩속도가 느릴 수 있습니다. | 초기 로딩속도가 빠릅니다. |

### 실전 팁
- Best Practice: 가능한한 getStaticProps를 사용하여 초기 로딩속도를 빠르게 만드는 것이 좋습니다.
- 흔한 실수와 해결법: getServerSideProps와 getStaticProps를 혼용하여 사용할 때, 데이터를 중복으로 가져오는 경우가 있으므로, 주의하여 사용하세요.
- 성능 관련 주의사항: 데이터를 가져올 때, 불필요한 데이터를 가져오지 않도록 주의하세요.

### 한 줄 정리
Next.js의 서버 액션과 데이터 페칭 패턴은 클라이언트 사이드 렌더링과 서버 사이드 렌더링을 모두 사용하는 하이브리드 아키텍처를 제공하여, 초기 로딩속도와 SEO를 개선할 수 있도록 도와준다.
