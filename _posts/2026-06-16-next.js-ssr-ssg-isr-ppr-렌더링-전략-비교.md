## 표면적 이해
Next.js는 SSR, SSG, ISR, PPR라는 렌더링 전략을 제공하여 개발자가 다양한 상황에 따라 적절한 전략을 선택할 수 있도록 한다.

## Deep Dive

### 왜 필요한가?
Next.js의 렌더링 전략은 웹 애플리케이션의 성능과 사용자 경험을 개선하는 데 도움이 된다. 이전 방식의 한계는 주로 클라이언트 사이드 렌더링만을 사용하여 초기 로딩 시간이 오래 걸리고, SEO 문제가 발생할 수 있다.

### 내부 동작 원리
Next.js의 렌더링 전략은 다음과 같은 핵심 메커니즘을 기반으로 한다.

```
                      +---------------+
                      |  요청(Request)  |
                      +---------------+
                             |
                             |
                             v
                      +---------------+
                      |  Routing      |
                      +---------------+
                             |
                             |
                             v
                      +---------------+
                      |  렌더링 전략  |
                      |  (SSR, SSG, ISR,|
                      |   PPR 등)       |
                      +---------------+
                             |
                             |
                             v
                      +---------------+
                      |  HTML 생성    |
                      +---------------+
                             |
                             |
                             v
                      +---------------+
                      |  응답(Response) |
                      +---------------+
```

### 코드로 이해하기

```typescript
// pages/index.tsx
import { GetServerSideProps } from 'next';

export const getServerSideProps: GetServerSideProps = async () => {
  // 서버 사이드 렌더링에서 사용될 데이터를 가져온다.
  const data = await fetchData();

  return {
    props: {
      data,
    },
  };
};

export default function Home({ data }) {
  return <div>{data}</div>;
}
```

### 비교 분석

| 구분 | SSR | SSG | ISR | PPR |
|------|-----|-----|-----|-----|
| 렌더링 시점 | 요청 시 | 빌드 시 | 요청 시 | 요청 시 |
| 성능 | 중 | | 중 | |
| SEO | 좋음 | 좋음 | 좋음 | 좋음 |

### 실전 팁
- SSR은 사용자 인터랙션에 적합하다.
- SSG는 정적 콘텐츠에 적합하다.
- ISR은 SSR과 SSG를 결합하여 사용할 수 있다.
- PPR은 캐시와 결합하여 사용할 수 있다.

### 한 줄 정리
Next.js의 렌더링 전략은 다양한 상황에 따라 적절한 전략을 선택하여 웹 애플리케이션의 성능과 사용자 경험을 개선하는 데 도움이 된다.
