## 표면적 이해
Next.js의 서버 액션과 데이터 페칭 패턴은 클라이언트와 서버 사이의 데이터 교환을 효율적으로 관리하는 방식을 제공합니다.

## Deep Dive

### 왜 필요한가?
- 이 기술이 해결하는 문제: 데이터 페칭과 서버 액션을 관리하는 것은 웹에서 매우 중요한 문제입니다. 특히, Next.js와 같은 서버 사이드 렌더링(SSR) 프레임워크에서는 데이터를 언제, 어떻게 불러와야 하는지 결정하는 것이 어려울 수 있습니다.
- 이전 방식의 한계: 이전에는 데이터 페칭을 위한 커스텀 훅이나 미들웨어를 사용했지만, 이는 코드의 복잡도와 유지 보수성을 증가시켰습니다.

### 내부 동작 원리
- 핵심 메커니즘 설명: Next.js의 서버 액션은 페이지를 렌더링하기 전에 서버에서 미리 처리할 수 있는 함수입니다. 데이터 페칭 패턴은 이 함수를 사용하여 필요한 데이터를 미리 불러오는 방식입니다.
- ASCII 다이어그램으로 시각화:
```
                       +---------------+
                       |  Client Request  |
                       +---------------+
                                  |
                                  |
                                  v
                       +---------------+
                       |  Server Action  |
                       |  (데이터 페칭)    |
                       +---------------+
                                  |
                                  |
                                  v
                       +---------------+
                       |  Page Rendering  |
                       |  (서버에서 렌더링) |
                       +---------------+
                                  |
                                  |
                                  v
                       +---------------+
                       |  Client-Side     |
                       |  Hydration      |
                       +---------------+
```

### 코드로 이해하기
```typescript
// getServerSideProps 함수를 사용하여 서버 액션을 정의
export const getServerSideProps = async () => {
  // 데이터 페칭 로직
  const data = await fetch('https://api.example.com/data');
  const jsonData = await data.json();

  return {
    props: {
      data: jsonData,
    },
  };
};
```
```typescript
// 잘못된 사용 예: 데이터 페칭을 클라이언트 측에서 처리
import { useState, useEffect } from 'react';

const HomePage = () => {
  const [data, setData] = useState([]);

  useEffect(() => {
    fetch('https://api.example.com/data')
      .then(response => response.json())
      .then(data => setData(data));
  }, []);

  return <div>{data.map(item => <div key={item.id}>{item.name}</div>)}</div>;
};
```
```typescript
// 올바른 사용 예: 서버 액션을 사용하여 데이터 페칭
import { GetServerSideProps } from 'next';

const HomePage = ({ data }) => {
  return <div>{data.map(item => <div key={item.id}>{item.name}</div>)}</div>;
};

export const getServerSideProps: GetServerSideProps = async () => {
  const data = await fetch('https://api.example.com/data');
  const jsonData = await data.json();

  return {
    props: {
      data: jsonData,
    },
  };
};
```

### 비교 분석

| 구분 | 클라이언트 측 렌더링 | 서버 사이드 렌더링 |
|------|--------------------|-------------------|
| 데이터 페칭 | 클라이언트에서 처리 | 서버에서 처리      |
| 성능      | 느릴 수 있음          | 빠름               |
| SEO       | 좋음               | 좋음               |

### 실전 팁
- Best Practice: 데이터 페칭은 항상 서버 액션에서 처리해야 합니다.
- 흔한 실수와 해결법: 데이터 페칭을 클라이언트 측에서 처리하면 성능이 느려질 수 있습니다. 해결 방법은 서버 액션을 사용하는 것입니다.
- 성능 관련 주의사항: 데이터 페칭을 서버에서 처리할 때, 성능을 개선하기 위해 캐싱을 사용해야 합니다.

### 한 줄 정리
Next.js의 서버 액션과 데이터 페칭 패턴은 데이터를 효율적으로 관리하여 빠른 페이지 렌더링을 제공하는 핵심 기술입니다.
