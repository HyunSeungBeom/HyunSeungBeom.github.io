## 표면적 이해
Prefetch, Preload, Preconnect 리소스 힌트는 웹 페이지의 성능을 verbess시키기 위해 브라우저가 리소스를 미리 로딩하거나 연결하는 기술입니다.

## Deep Dive

### 왜 필요한가?
- 이 기술이 해결하는 문제: 웹 페이지가 적절한 시간에 리소스를 로딩하지 못하여 사용자 경험이 저하되는 문제
- 이전 방식의 한계: 브라우저는 기본적으로 사용자 요청에 따라 리소스를 로딩하는 방식으로 작동하여 페이지 로딩 시간이 길어지는 문제가 있습니다.

### 내부 동작 원리
- 핵심 메커니즘 설명: 브라우저는 HTML 문서를 파싱한 후, 리소스 힌트를 발견하면 지정된 리소스를 미리 로딩하거나 연결합니다.
- ASCII 다이어그램으로 시각화:
```
                      +---------------+
                      |  HTML 문서   |
                      +---------------+
                             |
                             |  리소스 힌트 발견
                             v
                      +---------------+
                      | 리소스 미리 로딩  |
                      |  (Prefetch, Preload) |
                      +---------------+
                             |
                             |  리소스 연결
                             v
                      +---------------+
                      |  리소스 사용  |
                      +---------------+
```

### 코드로 이해하기
```typescript
// Prefetch 예
<link rel="prefetch" href="https://example.com/resource.js">

// Preload 예
<link rel="preload" href="https://example.com/resource.css" as="style">

// Preconnect 예
<link rel="preconnect" href="https://example.com">
```

```typescript
// 잘못된 사용 예: 리소스 힌트를 사용하지 않음
// 올바른 사용 예: 리소스 힌트를 사용하여 리소스를 미리 로딩함
```

### 비교 분석

| 구분 | Prefetch | Preload | Preconnect |
|------|---------|---------|------------|
| 리소스 로딩 | 미리 로딩 | 미리 로딩 | 연결만 설정 |
| 리소스 유형 | 모든 리소스 | 스타일, , 이미지 등 | 모든 리소스 |
| 사용 시점 | HTML 문서 파싱 후 | HTML 문서 파싱 후 | HTML 문서 파싱 후 |

### 실전 팁
- Best Practice: 리소스 힌트를 사용하여 중요한 리소스를 미리 로딩하거나 연결함으로써 사용자 경험을 verbess시키세요.
- 흔한 실수와 해결법: 리소스 힌트를 사용하지 않음, 리소스 힌트를 잘못 사용함. 해결법은 리소스 힌트를 올바르게 사용하여 리소스를 미리 로딩하거나 연결함입니다.
- 성능 관련 주의사항: 리소스 힌트를 사용하면 브라우저의 네트워크 요청이 될 수 있으므로, 사용 시점과 리소스 유형을 주의하여 사용하세요.

### 한 줄 정리
Prefetch, Preload, Preconnect 리소스 힌트를 사용하여 웹 페이지의 성능을 verbess시키고 사용자 경험을 향상시키세요.
